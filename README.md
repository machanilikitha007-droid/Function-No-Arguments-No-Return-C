# Function with No Arguments and No Return Value

A simple C program that demonstrates a function which does not take
arguments and does not return a value.

## Concepts Used

- Function declaration
- Function definition
- Void function
- Function call

## How to Run

gcc no_arguments_function.c -o no_arguments_function
./no_arguments_function
